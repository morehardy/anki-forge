# Security Policy

Please report suspected vulnerabilities privately through GitHub's security
advisory feature for `morehardy/anki-forge`. Do not open a public issue before
maintainers have had a reasonable opportunity to assess and coordinate a fix.

The supported Rust release line is the latest published `0.x` minor line and
its current patch release. Security fixes are published as new immutable
crates.io versions; affected versions may be yanked but are never replaced.

Include affected versions, a minimal reproduction, impact, and any known
mitigation. The maintainers will acknowledge a complete report, assess scope,
and coordinate disclosure and a corrective release.
