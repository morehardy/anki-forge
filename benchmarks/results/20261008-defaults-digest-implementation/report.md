# 默认值预生成与内存媒体摘要复用：正式实现

2026 年 10 月 8 日，基于 `15bcee61f58f904aba2e7c2a6ec8a086fb160cb9` 落地此前实验优先推荐的两项优化。4 并发媒体导入、16 MiB 编码池和 64 MiB 快照预算保持现有值；数据库查询缓存、连接复用及文本缓存未加入本次实现。

## 同会话性能对照

下表是重新构建的未修改版与正式实现的 release 二进制对照。两版使用默认产品 features、System allocator、相同输入和工具，串行交替测量。每版每场景 2 次预热、20 次计时、3 次独立 RSS；另有 16 个预检导出。百分比表示耗时下降，负数表示变慢。

| 场景 | 原版 → 正式版 ms | 耗时下降 | 峰值 RSS MiB | 配对节省区间 ms |
|---|---:|---:|---:|---:|
| 100 条文本 | 29.524 → 25.483 | 13.69% | 14.03 → 10.34 | [1.85, 6.36] |
| 1,000 条文本 | 54.983 → 53.258 | 3.14% | 25.33 → 22.03 | [0.37, 4.35] |
| 10,000 条文本 | 351.040 → 342.159 | 2.53% | 116.30 → 115.17 | [-3.01, 18.55] |
| 1,000 条宽字段 | 350.399 → 333.065 | 4.95% | 139.72 → 115.52 | [-0.60, 23.21] |
| 1,000 条独立图片 | 153.115 → 147.695 | 3.54% | 94.77 → 92.50 | [-2.26, 11.23] |
| 1,000 条独立音频 | 135.301 → 126.027 | 6.85% | 65.22 → 62.84 | [2.82, 15.91] |
| 1,000 条共享媒体 | 63.278 → 63.035 | 0.38% | 32.28 → 29.34 | [-0.49, 4.39] |
| 100 条文本 + 16 个 2 MiB 文件 | 81.791 → 77.192 | 5.62% | 37.33 → 32.62 | [-1.40, 7.46] |

区间是同轮次配对节省耗时的描述性 95% bootstrap 区间，固定种子、10,000 次重采样，未做多重比较校正。区间跨零的场景不足以证明稳定收益。所有样本保留，没有选择性重跑。完整中位数、四分位数、极值及原始样本见 [analysis.json](analysis.json)，扁平结果见 [comparison.csv](comparison.csv)。

本轮 100/1,000 条文本和千条音频的配对区间均为正，支持改善；另外五个场景虽然中位数下降，区间均跨零，不能据此承诺稳定提速。图片的本轮降幅小于原型实验，完整保留这一差异。八个场景 RSS 中位数均降低；宽字段下降 24.20 MiB 是 3 次独立进程的本机观测，尚未进一步隔离其内存分配机制，不能将其推广为固定节省量。

这次比较测量正式组合相对当前提交的增益。单项归因依据[前一轮隔离实验](../20261008-residual-paths/report.md)，不能把组合改善全归于摘要复用。也不能把本轮降幅直接套到 9 月 21 日的跨会话数字；此前完整 20 格历史比较保留在[上一份报告](../20261008-media-defaults-genanki/report.md)。

## 实现

- **内置默认值在 Cargo 构建阶段生成。** `build.rs` 直接复用完整 bundle 解码器、manifest 校验器和配置类型；验证归档完整性、路径、资产清单、版本和 YAML 配置后，将类型化 JSON 写入 `OUT_DIR`。运行时只加载生成的数据，保留 `OnceLock`。bundle 或共享源码变化会重新生成；无效 bundle 使构建失败，不会静默回退旧结果。使用者无需手动运行生成命令。
- **仅复用私有不可变内存快照的 BLAKE3。** 资格由实际存储类型判断；普通文件、独立临时快照文件和共享 spill 分段均继续重算。仍读取全部内容并计算 SHA-1、检查大小、提取 MIME 样本、编码和核验最终包。
- 抽出共享校验模块和配置模型，保留原有内部引用路径；更新 Cargo 分发清单、changelog 和 [ADR 0027](../../../docs/adr/0027-build-time-defaults-and-immutable-media-digests.md)。公共 API 和 bundle 格式未变，没有实验开关或额外生产计时代码。

默认值优化主要影响冷进程第一次初始化；同进程后续构建此前已命中 `OnceLock`。新增 host 构建依赖可能增加全新编译的成本，本轮没有将依赖缓存下的构建耗时作为性能结论。单个媒体大于 1 MiB 或超出共享预算后落盘，仍需完整 BLAKE3；总 RSS 也不是上述预算之和的硬上限。

适配器已有阶段计时如下。端到端还包含进程启动与退出，这些阶段中位数不能相加还原总中位数：

| 场景 | 输入/导入 ms，原版 → 正式版 | 构建操作 ms，原版 → 正式版 |
|---|---:|---:|
| 100 条文本 | 0.360 → 0.345 | 25.070 → 22.256 |
| 1,000 条文本 | 2.135 → 2.141 | 49.295 → 47.248 |
| 10,000 条文本 | 20.609 → 20.496 | 324.618 → 315.839 |
| 1,000 条宽字段 | 25.942 → 26.122 | 316.621 → 301.425 |
| 1,000 条独立图片 | 30.914 → 31.729 | 118.606 → 112.295 |
| 1,000 条独立音频 | 25.901 → 25.618 | 105.555 → 95.503 |
| 1,000 条共享媒体 | 4.004 → 3.915 | 56.025 → 55.760 |
| 100 条文本 + 16 个 2 MiB 文件 | 12.777 → 11.629 | 63.309 → 59.148 |

## 正确性和分发验证

- Rust 默认核心 170 项、all-features 核心 408 项通过；完整 workspace/all-features 测试、公共 consumer、doctest、Clippy（所有 targets/features，`-D warnings`）、rustfmt 和文档构建通过。原有 ignored 项保持原状态。
- 生成默认值与共享解码器、完整文件路径加载器逐值相等。损坏 gzip、重复/冲突归档条目、越界路径、manifest 和无效配置测试均通过。
- 两个新增公共 consumer 测试分别篡改独立快照文件和预算耗尽后的 spill 分段，均得到 `MEDIA.SOURCE_CHANGED`，没有发布文件或临时文件泄漏。这些测试先在修改前通过，再随完整测试验证修改后行为。
- Cargo 打包清单、bundle 一致性、版本元数据及依赖例外检查通过。将 `.crate` 解包到 `/tmp`，在仓库外生成锁文件、编译并运行官方 consumer；复用了依赖构建缓存。已有生成结果的情况下损坏默认 policy，下一次构建正确失败；恢复 bundle 后再次成功。[分发验证记录](package-check.json)保存命令和结果。
- 重新构建 Node/Python 本机 native 绑定：Node 30 项通过、1 项跳过；Python 68 项通过、1 项跳过；mypy 14 个文件通过。未测这两种宿主的性能，未运行跨平台 CI。
- 416 次导出全部通过原始结构、内容、媒体和语义核验；32 个代表样本实际通过 Anki 导入。所有场景两版的逻辑摘要一致，临时目录清理完整。
- 首次 Rust 质量脚本仅在清单排序处停止，按 Cargo 实际顺序修正后剩余检查通过。独立分发验证脚本首次调用了旧 Python 不支持的 tar 解包参数，修正验证脚本后通过。失败日志也保留在归档中；这些修正都在正式测量之前完成。

## 测量范围和证据

使用本机 macOS arm64、Rust 1.92，AC 供电，全部 exporter 串行，无构建或测试并行运行。OS 页缓存和桌面后台调度未隔离。计时从直接子进程启动到退出，核验、Anki 导入和清理均在该计时之外。每个场景轮换先后顺序；RSS 来自另外的独立进程。

生产源码和二进制在测量前冻结，测量后重新核对 SHA-256。Anki oracle 复用既有已验证的可执行文件，重新检查了其 SHA 和全部记录的 checker 源码/锁文件；未声称重新编译 Anki。详情见 [oracle-reuse-check.json](oracle-reuse-check.json)、[质量检查](quality.json)和[审计](audit.json)。

[生产补丁](production.patch)包含全部新增 Rust 源文件。[证据归档](evidence.tar.gz)保存原版/候选源码、脚本、输入 JSON、逐样本测量与核验记录、Anki 结果、构建和测试日志。二进制、媒体载荷和成功 APKG 未归档，但保留摘要；成功 APKG 验证后删除，媒体原件仍在本地工作目录。[文件清单](archive-manifest.json)和[归档摘要](evidence-sha256.json)用于完整性核对。

运行 `python3 benchmarks/results/20261008-defaults-digest-implementation/replay.py` 可验证归档并重算统计。这是记录复核，不是重新导出或再次导入 Anki。
