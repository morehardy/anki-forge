# ADRs

This directory records contract decisions that need a durable paper trail.

- Use one ADR per decision.
- Number ADRs sequentially as `NNNN-short-slug.md`.
- Keep the content focused on rationale and consequences, not implementation
  walkthroughs.
- Add or update an ADR before merging changes that affect contract meaning,
  compatibility, or bundle governance.
