# README artwork and sample deck

The artwork is built from exported cards and the archived benchmark data.
`showcase.apkg` contains three notes/cards and two media files, all generated by
the [showcase example](../../../anki_forge/examples/readme_showcase.rs).
The audio is a quiet, one-second 440 Hz sine tone, not a recorded instrument.

## What the card previews show

[Anki's Rust renderer](../../../scripts/roundtrip_oracle/src/bin/readme_render.rs)
imports the APKG into a temporary collection and captures its question HTML,
answer HTML, and note-type CSS. It also copies media that Anki actually imported.
The retained [rendered content](source/cards.json) records the sample APKG's SHA-256.

The preview adds a neutral font, colors, and outer spacing where stock note types
do not define them. Anki sound markers are displayed with a native browser audio
control using the same imported WAV; Anki Desktop supplies its own replay button.
The ear-training note type's CSS is included in the APKG. The waveform is an
illustration, not a time-calibrated plot. Surrounding labels are documentation.
These are previews of Anki-rendered content, not screenshots of the Desktop UI.

The Basic card's content and template match the
[quick-start example](../../../anki_forge/examples/target_api_basic.rs). Cloze
previews show both the question and answer, including Anki's cloze markup.
Dark previews add the `nightMode` class used by the note-type CSS.

## Regenerate

Run these commands from the repository root. Rust 1.92.0 is required. The
independent renderer additionally needs the local upstream Anki source and
`protoc`; see the [Anki oracle setup](../../../benchmarks/README.md).

```sh
cargo run --locked -p ankiforge --example readme_showcase -- target/readme/showcase.apkg
cargo run --locked --manifest-path scripts/roundtrip_oracle/Cargo.toml --bin readme_render -- target/readme/rendered target/readme/showcase.apkg
MPLCONFIGDIR=target/readme/matplotlib benchmarks/.venv/bin/python scripts/generate_readme_assets.py --cards target/readme/rendered/cards.json --package target/readme/showcase.apkg
```

The Python script uses matplotlib from the benchmark environment. To regenerate
charts and preview pages from the retained rendering without rebuilding Anki:

```sh
MPLCONFIGDIR=target/readme/matplotlib benchmarks/.venv/bin/python scripts/generate_readme_assets.py
```

This writes four benchmark SVGs here and eight screenshot source pages under
`target/readme/preview/`. The source pages contain the card HTML, CSS, and inline
media, with no external requests. Each page's `main.art` is the capture rectangle:

| Artwork | Desktop size | Mobile size |
| --- | --- | --- |
| `code-to-card-{light,dark}` | 1000 × 535 | 440 × 764 |
| `card-showcase-{light,dark}` | 1000 × 603 | 440 × 1113 |

Serve the preview directory on loopback and capture each page at its declared
width, saving the `main.art` bounds as the corresponding PNG in this directory:

```sh
python3 -m http.server 8769 --bind 127.0.0.1 --directory target/readme/preview
```

For example, `code-to-card-light.html` produces `code-to-card-light.png`.
Verify images and audio metadata have loaded, let viewport resizing finish, and
check that the saved image dimensions match the full artwork before replacing
assets. Browser audio-control appearance and font rasterization can vary by OS.
Confirm the output is PNG; some screenshot tools return JPEG bytes by default.

## Benchmark provenance

The charts use only the 1,000-note rows in the archived
[comparison CSV](../../../benchmarks/results/20260921-readme-genanki/comparison.csv).
They show both implementations for all five workloads on a shared linear axis
starting at zero. Each value is the median of 10 runs. Light/dark and mobile
variants use identical values.

The [full report](../../../benchmarks/results/20260921-readme-genanki/report.md)
contains sample spread, memory measurements, format differences, and source
provenance. Regenerating the README artwork does not rerun or modify that benchmark.

## Update example check

The [update example](../../../anki_forge/examples/readme_update.rs) builds a first
package and a revision against that package. To check both imports in the same
temporary Anki collection:

```sh
cargo run --locked -p ankiforge --example readme_update -- target/readme/updates
cargo run --locked --manifest-path scripts/roundtrip_oracle/Cargo.toml --bin readme_render -- target/readme/updated target/readme/updates/spanish-v1.apkg target/readme/updates/spanish-v2.apkg
```

`target/readme/updated/cards.json` should contain one card with the fields
`["hola", "hello; hi"]`.
