# 中英共性与完整西语候选：最终验收

2026-10-28。源提交 `a9b3fa044f1ae166ecd8007d68f3b864230ddc00`。**中英共性改造及西语 34 主题已完成本地双配置完整验收；尚未推送或部署。** 代码位于 `codex/multilingual-spanish` 独立工作树，原中英工作区保留其已验收版本。

## 交付

西语完整覆盖 29 篇文档、2 篇文章、首页、示例及博客列表；包含 210 条 UI 文案、11 个框架覆盖项、29 组文档标题／摘要、三套 SDK 的西语 AI 指令模板。实际参与构建的词典、元数据、导航、侧栏、模板及技术输入均进入相应源审核闭包。代码、API 名称、版本、稳定身份和可执行输入按合同保留。

每语整套发布；未启用的其他已注册语言不进入链接、索引、页面或机器导出。源审核与构建后证据分开校验，缺证或摘要变化时发布失败。

检索用例是 AI 编写的验收样例，不是实际用户搜索或搜索量。词汇作者未读取题集和结果；查询作者参与过翻译规划，不能宣称完全盲于页面主题。两个实际检索缺口通过通用创建／运行语境数据修正，未添加“查询→页面”规则或修改引擎。

SDK 执行明确复用既有真实结果。独立核对发现原 20 个输入中 19 个字节未变；变化的 AI 控制 JSON 仅新增本地化数据，其版本、安装命令、运行环境及入口投影相同。185 个 SDK 文件、5 份英文安装文档和 3 份实际执行的最小程序均相同。没有声称为每种语言重新运行 SDK 或 Anki GUI。

## 发现并关闭的问题

共性阶段关闭审校输入闭包与构建后证明缺失，并修正主题控件随机标识导致的重建不稳定。西语阶段修正独立 AI 发现的对象、术语和措辞问题；正式站点检查进一步发现两篇文章的语义标记未生成实际锚点，发布被拒绝。补齐 8 个明确锚点后重新复审、构建及验收。初次失败、旧产物和旧报告均保留，不冒充最终通过证明。

中文一条既有变体查询未命中前三，但符合预先固定的至少 23/25 正例门槛；中英 23 条既有 minor 表达观察保留。未把它们统计成西语错误，也未删除这些记录。
