- 语言质量：用户明确“使用独立的AI审校修改后即可，不需要母语验证”。实现采用独立 AI 盲读、技术对照、搜索／任务检查、修订和独立复审，不设置真人审校要求。
- 发布范围：用户确认“是，每语完整后发布”。当前每种语言覆盖全部 32 个主题，样本阶段仅在隔离预览进行。
- 最终范围：用户确认“是，按此完整方案收敛”，锁定既有 en／zh-CN 与新增 es、pt-BR、ja、de、fr、ru，以及下述推进队列。

已确认队列：既有 en／zh-CN 共性改造 → es → pt-BR → ja／de → fr／ru。印尼语保留后续候补。方案确认不等于已经执行代码或发布。

## 争议与收敛结果

| 被质疑的说法 | 查证或反对理由 | 收敛处理 |
| --- | --- | --- |
| 当前检查已足以保护 SEO | 检查依赖当前 registry；旧页连同注册项删除仍可能自洽；正常页 noindex 与 headers 也缺保护 | 增加来自旧发布实际产物的公开面基线、索引／摘要资格和 HTTP header 检查 |
| SEO/GEO 可以保证完全不受影响 | 排名、平台抓取和模型引用受外部系统影响 | 承诺无已知工程回归，并以真实观测判断后续效果 |
| 标题深度和表格形状相同就说明翻译完整 | 当前按下标配对阻碍自然重组；结构相同也可能错译 | 保护稳定任务／章节 ID、事实、代码、数据和依赖步骤，独立 AI 对照正文 |
| 旧锚点只要存在即可 | 所有别名放页顶仍不能恢复原来的任务上下文 | 旧 DOM 基线加实际章节语义验收；条件仍贴近结论 |
| 用多个 AI 一致打分证明地道 | 模型可能共同遗漏；作者自评会偏向原稿 | 独立单语盲读、具体问题证据、修订后独立复审；reviewerType 明确为 ai |
| 需要母语人工团队 | 用户明确不需要 | 删除人工 gate 和相关预算，所有发布检查由独立 AI 与工具完成 |
| 核心页先发天然更简单 | SEO 允许部分译文，但本站 strict parity、导航和 fallback 机制会增加额外实现范围 | 用户选整语完成；部分译稿只作编辑预览 |
| 第一批 es 和 pt-BR 必须一起上线 | 绑定发布时间使已完成语言被等待，也扩大排障范围 | es 完整试点；pt-BR 可并行准备、独立过闸 |
| 继续使用原 6–8 周与 48–78 人日 | 原估算依赖未确认且已被取消的人工审校资源 | 用首语真实代理和构建耗时估算，不编造新日期 |
| Pagefind 搜索通过就是自然搜索验证通过 | 站内目标命中与外部需求、索引、排名是不同观测 | 30 条站内夹具与 GSC 真实查询分开，拟写关键词明确标种子 |
| 一有流量下降就整站回滚 | 可能仅是语言份额转移或外部变化；旧 artifact 会删除新语言 URL | 明确工程故障才触发应急恢复；稳定新语言优先前滚或保留内容回退共享代码 |
| GEO 应先增加 llms 和大量 schema | 官方指导没有特殊门槛；额外管线增加维护成本 | 优先任务正确、事实来源、静态正文、索引与摘要资格；其他增强按真实需求单独推进 |

终审追加两项质量修订：自然度改为四个分项均达标；每轴审校证据绑定实际输入快照与最终构建产物，首页等共享组件的词典和元数据纳入 targetHash。

初次终审发现工作区有并行的机器读取／结构化数据实现，完整方案因此新增 C11。随后用户要求具体评估两份方案是否冲突，本次确认实现已经提交为 `2c07690`；它们并非扩语重新创建的 SEO 功能，也不能因 Google 没有特殊门槛而移除。代码已提交和生产已验证分别记录。

## 机器读取方案对齐补充

SEO/GEO 与语言质量两个子代理独立核对规格及实现，再就发布集合、语义保真和审核证据交叉讨论，形成[对齐评估](machine-readable-alignment.md)。完整方案已吸收以下结论：

- 继承真实 HTML→Markdown、llms、JSON-LD、资源清单与 HTTP 合同；所有双语分支、输出路径、清理和检查器同批泛化。
- 旧公开面同时保护已验证上线的机器 URL、发现关系与实体身份，保留内容更新产生新 hash 的空间。
- 区分 configuredLocales、sourceReady、releaseLocales 和 verified published；最终构建前固定发布集合，验收后发布同一 artifact，不靠改 catalog 状态重建。
- 源审校在构建前，搜索／任务／机器／浏览器证明在构建后，后者不回写参与 inputSha256 的 content-reviews.json。
- 固定 Optional、Markdown 头标签和协议标识不翻译；其自然语言值与机器摘要仍独立审校。跨语允许自然重组，同语导出必须忠于本地 HTML。
- 机器规格的人工读取验收改为独立 AI 执行并留证，遵守用户已经确认的选择。每语完整性扩展到 32 HTML、29 Markdown、1 llms；六语范围和队列不变。

本次未改机器规格及网站实现，也没有运行构建、测试或重新验证生产。新增验收条目是实施要求，不能当作本轮已通过结果。
