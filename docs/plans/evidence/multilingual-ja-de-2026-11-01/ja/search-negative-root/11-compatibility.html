    互換性と検証済みの環境

    パッケージと検証済みの環境

    「パッケージと検証済みの環境」のセクション

    2026-10-13の確認時点で、Rust・npm・PyPI の公開パッケージは 0.3.1 です。Rust、Node / TypeScript、Python から始めてください。

    インターフェース パッケージ 実行環境と検証
    Rust ankiforge 0.3.1 Rust 1.92.0 と検証時の stable。対応する4プラットフォームすべてでパッケージ利用側を検査し、公開 crates.io パッケージの新規利用側も確認
    Node / TypeScript ankiforge 0.3.1 Node 22.13.0、検証時の22・24・26。公開 npm からのインストール、ESM/CJS、TypeScript の16件の検査
    Python ankiforge 0.3.1 通常の CPython 3.11〜3.14。隔離環境で公開 PyPI wheel をインストールする16件の検査

    公開ネイティブパッケージは macOS arm64/x64、Linux x64 GNU/glibc、Windows x64 に対応します。パッケージが存在するだけで、すべてのホストで実行テストが成功したことにはなりません。Node の検証範囲、Python の検証範囲、リリースの証拠に、実施した検査を記録しています。0.3.1 の成功したリリース実行は Rust、npm、PyPI です。他の Python 実装、free-threaded インタープリター、サブインタープリターは別途検証が必要です。ブラウザー、Electron、Bun、Alpine/musl、ARM64 Linux/Windows は、記録済みの Node 検証範囲外です。

    メディアの一括インポートと準備済み公開のガイドで扱う機能は、公開 0.3.1 パッケージで使用できます。

    Anki でのインポートと再生

    「Anki でのインポートと再生」のセクション

    通常のエクスポートに Anki のインストールは必要ありません。インポート、描画、メディアの再生は、対象クライアントのバージョン、コーデック、インポート設定に依存します。2026-10-08のベンチマークでは、Anki へのインポート・内容・代表的な描画の検査40件（各実装20件）が成功しました。すべてのクライアントや GUI・音声動作を検証したものではありません。

    更新用に、前回配布時のオリジナル APKG を保持してください。Anki から再エクスポートしたファイルには、必要な識別情報の証拠が残りません。パッケージからノートを省いても、学習者のコレクションからは削除されません。フィールド・テンプレートの変更、並べ替え用フィールド、ローカルの編集、復習履歴は、クライアントごとのテストが必要です。

    自分の配布物は、手動クライアント検証シナリオと、それぞれの参照検証で指定した正確な Anki のバージョン・設定で評価してください。クライアント側の条件とファイル単位の公開動作は、更新とビルドの保証を参照してください。
