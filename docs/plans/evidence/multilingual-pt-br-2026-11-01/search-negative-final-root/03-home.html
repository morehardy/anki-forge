Rust

Instruções para a IA · Anki Forge 0.3.1
Ajude-me a usar Anki Forge 0.3.1 em uma aplicação Rust.
Requisito de execução: Rust 1.92+

Use o pacote publicado `ankiforge` e somente a API pública documentada para
esta versão. Não use dependências git/path, ferramentas internas, APIs
exclusivas do código-fonte, métodos não publicados ou métodos inventados.

Minha tarefa:
<descreva sua tarefa>

Por favor:
1. Examine o projeto existente antes de alterar arquivos.
2. Informe a configuração necessária e o comando exato de instalação: cargo add ankiforge@0.3.1
3. Crie o menor programa completo e executável e indique cada arquivo a criar ou editar.
4. Gere um arquivo `.apkg` persistente e use namespace e chaves de nota estáveis.
5. Inclua o comando de execução, a saída esperada e uma etapa de verificação.
6. Se a tarefa precisar de mídia, modelos personalizados, oclusão de imagem ou
   atualizações, siga o fluxo documentado em vez de presumir a API. Para atualizar,
   guarde o APKG original distribuído da versão anterior como base; não use
   uma reexportação do Anki.
7. Faça somente as perguntas necessárias para esclarecer a linguagem, o formato
   da entrada, o caminho de saída ou a regra de identidade.

Referência de início rápido: https://ankiforge.dev/pt-br/docs/quickstart/

let (front, back) = ("hola", "hello");
let mut project = Project::new("spanish")?.default_deck("Spanish");
project.add("es:hola", Note::basic(front, back))?;
let built = project.build(BuildOptions::to(output.join("spanish.apkg")))?;
