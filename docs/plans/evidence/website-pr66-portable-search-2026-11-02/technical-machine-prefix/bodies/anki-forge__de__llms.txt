# Anki Forge

> Anki Forge erzeugt Anki-APKG-Stapel aus Code mit Rust, Node / TypeScript oder Python.

Aktuelle Version des veröffentlichten Pakets: 0.3.1. Für einen gewöhnlichen Export muss Anki nicht installiert sein. Die APIs veröffentlichter Pakete unterscheiden sich von Builds aus dem Quellcode. Bewahre für Aktualisierungen das ursprünglich verteilte APKG der Vorgängerversion auf; Ankis Importeinstellungen und neuere lokale Änderungen können das Ergebnis beeinflussen.

- Rust: `cargo add ankiforge@0.3.1` (Rust 1.92+)
- Node / TypeScript: `npm install --include=optional ankiforge@0.3.1` (Node.js 22.13+)
- Python: `python -m pip install ankiforge==0.3.1` (CPython 3.11+)

## Anleitungen nach Aufgabe

- [CSV zu Anki: Karten mit Python erzeugen](https://morehardy.github.io/anki-forge/de/docs/csv-to-anki/index.md): Wandle eine UTF-8-Vokabeltabelle mit einem vollständigen Python-Skript in ein Anki-APKG um – mit CSV-Beispiel, stabilen Notiz-IDs und Importprüfungen.
- [Anki-Stapel aus JSON erzeugen und aktualisieren](https://morehardy.github.io/anki-forge/de/docs/json-to-anki/index.md): Lies JSON mit Rust, Python oder TypeScript ein, bündle Bilder und Audio und prüfe eine APKG-Aktualisierung, die nur eine Antwort ändert.
- [Anki-Karten mit KI-Unterstützung: von Aufzeichnungen zum APKG](https://morehardy.github.io/anki-forge/de/docs/ai-anki-cards/index.md): Lass einen KI-Assistenten Karten entwerfen, prüfe die Antworten und exportiere mit Anki Forge ein APKG. Nutze CSV oder eine Aufgabenbeschreibung für Programmierassistenten.
- [Basic- und Cloze-Karten für Anki erzeugen](https://morehardy.github.io/anki-forge/de/docs/cards/index.md): Erzeuge Basic-Karten mit Frage und Antwort sowie Cloze-Lückentextkarten aus Code. Ein geprüftes Rust-Beispiel erstellt zwei Notizen und drei Karten.
- [Anki-Karten um Bilder und Audio ergänzen](https://morehardy.github.io/anki-forge/de/docs/media/index.md): Importiere mit Rust, Python oder Node.js Dateien, kombiniere Karteninhalte und verwalte Exportnamen, MIME-Typen und Medienbudgets.
- [Anki-Kartenvorlagen, CSS und Medien wiederverwenden](https://morehardy.github.io/anki-forge/de/docs/templates/index.md): Lade einen wiederverwendbaren Anki-Notiztyp aus einem Paket mit Kartenvorlagen, CSS und Medien – für normale oder Cloze-Karten mit Rust, Python oder Node.js.
- [Anki-Karten mit Bildverdeckung erzeugen](https://morehardy.github.io/anki-forge/de/docs/image-occlusion/index.md): Erzeuge Bildverdeckungskarten per Code mit Rust, Python oder Node.js: Gib Bild und Rechteckmasken vor und wähle einen der beiden Verdeckungsmodi.
- [Anki-Stapel mit stabilen Notiz-IDs aktualisieren](https://morehardy.github.io/anki-forge/de/docs/updates/index.md): Veröffentliche eine neue Stapelversion: Behalte stabile Notiz-IDs bei, verwende das ursprüngliche APKG der Vorgängerversion als Basis und prüfe den Vergleich vor der Verteilung.
