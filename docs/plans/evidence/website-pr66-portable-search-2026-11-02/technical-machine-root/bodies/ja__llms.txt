# Anki Forge

> Anki Forge は Rust、Node / TypeScript、Python のコードから Anki APKG デッキを生成します。

現在の公開パッケージのバージョン: 0.3.1。 通常のエクスポートに Anki は必要ありません。公開パッケージの API とソースビルドは異なります。更新には前回配布時のオリジナル APKG を保持してください。Anki のインポート設定と新しいローカル編集が結果に影響する場合があります。

- Rust: `cargo add ankiforge@0.3.1` (Rust 1.92+)
- Node / TypeScript: `npm install --include=optional ankiforge@0.3.1` (Node.js 22.13+)
- Python: `python -m pip install ankiforge==0.3.1` (CPython 3.11+)

## 作業別ガイド

- [Python で CSV を Anki カードに変換する](https://ankiforge.dev/ja/docs/csv-to-anki/index.md): UTF-8 の語彙表を Anki APKG に変換する完全な Python スクリプト。CSV サンプル、安定したノート ID、インポート確認の手順を含みます。
- [JSON から Anki デッキを生成・更新する](https://ankiforge.dev/ja/docs/json-to-anki/index.md): Rust、Python、TypeScript で JSON を読み取り、画像と音声を同梱し、解答だけを変更する APKG 更新を確認します。
- [AI を使った Anki カード作成：学習メモから APKG へ](https://ankiforge.dev/ja/docs/ai-anki-cards/index.md): AI アシスタントでカードの下書きを作り、解答を確認して Anki Forge で APKG を生成。CSV の手順とコーディングアシスタント向け依頼文を用意しています。
- [Anki の Basic と Cloze カードを生成する](https://ankiforge.dev/ja/docs/cards/index.md): コードで質問・解答の Basic カードと穴埋めの Cloze カードを生成。検証済みの Rust サンプルは2件のノートから3枚のカードを作ります。
- [Anki カードに画像と音声を追加する](https://ankiforge.dev/ja/docs/media/index.md): Rust、Python、Node.js で画像・音声をインポートしてカードを組み立て、エクスポート名、MIME タイプ、メディア上限を管理します。
- [Anki のカードテンプレート、CSS、メディアを再使用する](https://ankiforge.dev/ja/docs/templates/index.md): Rust、Python、Node.js でテンプレート、CSS、メディアのバンドルから、通常・Cloze カード用の再使用可能なノートタイプを読み込みます。
- [Anki の画像穴埋めカードを生成する](https://ankiforge.dev/ja/docs/image-occlusion/index.md): Rust、Python、Node.js で画像と指定した矩形マスクから画像穴埋めカードを作ります。2つの遮蔽モードに対応しています。
- [安定したノート ID で Anki デッキを更新する](https://ankiforge.dev/ja/docs/updates/index.md): ノート ID を維持し、前回配布時のオリジナル APKG を基準にビルドして、比較を確認してから新バージョンを配布します。
