# Anki Forge trial and feedback

Use the public package for your own task: start at the relevant English or Chinese
quickstart, then follow JSON generation and update. Keep the original v1 APKG.
The JSON biology deck is a maintainer example, not a user adoption case study.

Record SDK/runtime/OS, installed version and registry source; your input/task;
entry URL/language; installation and run commands; first success or exact failure;
APKG counts; comparison/policy result; Anki version and import settings; whether
v2 replaced the answer without duplicates; image and audio behavior; local edits
or review-state concerns; and what prevented or encouraged continued use.
Include reproducible logs or a public downstream link, with permission to cite it.
Do not include credentials, private learner data or unrelated personal information.
