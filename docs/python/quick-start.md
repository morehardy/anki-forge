# Python Quick Start

Build or install the native Python 0.2 package as described in the
[package guide](../../bindings/python/README.md#from-a-source-checkout).

```python
from anki_forge import Field, Note, NoteType, Project, Template

project = Project("Japanese", stable_id="jp-core", default_deck="Japanese::Core")
project.add_notetype(NoteType.custom("vocabulary")
    .field(Field("Expression", key="expr", identity=True, sort=True, required=True))
    .field(Field("Meaning", key="meaning"))
    .template(Template("Recognition", key="recognition", front="{{Expression}}", back="{{Meaning}}")))
project.add_note(Note("vocabulary").text("expr", "食べる").html("meaning", "<b>to eat</b>"))
project.write_apkg("japanese.apkg").ensure_success()
```

Keep stable project IDs, note IDs and field/template keys across updates. Project
settings are read-only. To create an updated deck, construct the desired new
Project with the same stable identities. Additions capture input snapshots;
editing a previously added Note/NoteType does not mutate the project.

## Media

```python
from anki_forge import Note

# taberu.mp3 must exist and remain unchanged until build finishes.
audio = project.media.add_file("taberu.mp3", export_as="taberu.mp3")
project.add_note(Note.basic("Pronunciation", "", stable_id="audio:taberu").sound("back", audio))
project.write_apkg("japanese-with-audio.apkg").ensure_success()
```

`add_bytes(source_label=..., data=..., export_as=...)` accepts at most 64 KiB and
rejects empty data. `MediaError` retains core error codes. Relative paths use
`base_dir` captured at Project construction. Template bundle, Deck, update safety,
Artifact, bytes and file-object examples are in the
[runnable native workflow](../../bindings/python/examples/native_workflow.py).

Independent Projects can run concurrently. Each Project/Deck permits one active
operation and rejects competing operations. Caller-owned mutable authoring inputs
are not thread-safe. See [migration](../../bindings/python/MIGRATION.md) before
updating projects generated by Python 0.1.
