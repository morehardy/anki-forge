# RFCs

Use an RFC when a contract change needs broader discussion than an ADR can
capture.

- Start an RFC for changes that cross team boundaries or alter compatibility
  semantics.
- Keep the proposal focused on the decision that needs review.
- Link the RFC to the relevant ADRs and contract assets so reviewers can see the
  full trail.
