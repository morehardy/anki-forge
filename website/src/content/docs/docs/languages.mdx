Use Rust, Node / TypeScript or Python to connect Anki deck generation to your data.
All three can export a persistent `spanish.apkg` without installing Anki.

| Language | Public package | Install | Complete first deck |
| --- | --- | --- | --- |
| Rust | [ankiforge 0.2.0](https://crates.io/crates/ankiforge) | `cargo add ankiforge@0.2.0` | <a href={sitePath('/docs/quickstart/')}>Rust quickstart</a> |
| Node / TypeScript | [ankiforge 0.2.0](https://www.npmjs.com/package/ankiforge) | `npm install --include=optional ankiforge@0.2.0` | <a href={sitePath('/docs/node-quickstart/')}>Node quickstart</a> |
| Python | [ankiforge 0.2.0](https://pypi.org/project/ankiforge/) | `python -m pip install ankiforge==0.2.0` | <a href={sitePath('/docs/python-quickstart/')}>Python quickstart</a> |

Rust needs Rust 1.92+. Node needs Node 22.13+ and a matching native optional dependency.
Python uses a native wheel for an ordinary CPython interpreter; CPython 3.11/3.12
are verified in recorded package checks. See <a href={sitePath('/docs/compatibility/')}>verified environments</a>.
