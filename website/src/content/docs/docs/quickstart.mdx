This guide runs the repository’s minimal Rust example. You need Git, Rust 1.92 or later, and Anki to review the result.

## Run the example

```bash
git clone https://github.com/morehardy/anki-forge.git
cd anki-forge
cargo run -q -p ankiforge --example target_api_basic
```

The first run compiles the project and its dependencies. It writes `spanish.apkg` in the repository root. The following source is taken directly from `anki_forge/examples/target_api_basic.rs`:

## Open the deck

Open `spanish.apkg` with Anki, confirm the import, and open the **Spanish** deck. The card asks **hola**; reveal the answer to see **hello**.

You can also <a href={sitePath('/generated/spanish.apkg')}>download the website’s Basic example</a> to try the result before compiling.

## Read the code

`Project::new("spanish")` creates a publication namespace; `default_deck("Spanish")` selects its display deck. `Note::basic` creates front and back fields, and `project.add("hola", note)` assigns a stable note key independent of wording.

`project.build(BuildOptions::to(...))` returns a successful output with an artifact or a typed error. The `?` operator propagates failures. See <a href={sitePath('/docs/build-guarantees/')}>build and output guarantees</a> for reports and ownership.

## Make it yours

To use the library outside this checkout, follow <a href={sitePath('/docs/installation/')}>Add to your application</a>. The <a href={sitePath('/docs/concepts/')}>core concepts</a> explain projects, notes, cards and owned resources.

Add another note with a different stable ID, change the deck name, or try a <a href={sitePath('/examples/#cloze')}>Cloze example</a>. For custom fields and media, use the project API and <a href={sitePath('/docs/templates/')}>template bundles</a>.

Before updating a deck that you have already distributed, keep a copy of the previous package. The <a href={sitePath('/docs/updates/')}>update guide</a> explains comparisons and updates from the original distributed APKG.
