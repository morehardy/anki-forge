Use Rust 1.92 or later. For another language, choose
<a href={sitePath('/docs/languages/')}>Node / TypeScript or Python</a>.

## Install

```sh
cargo new anki-deck
cd anki-deck
cargo add ankiforge@0.2.0
```

## Export your first deck

Save this complete program as `src/main.rs`:

<CodeBlock code={quickstartSource} />

```sh
cargo run
```

The program writes a persistent `spanish.apkg`. Open it in Anki, import it and
study **hola → hello** in the **Spanish** deck. Exporting needs no Anki installation.

The namespace `spanish` and stable key `es:hola` identify this note through later
content changes. You can also <a href={sitePath('/generated/spanish.apkg')}>download the website's Basic example</a>.
